Project Idea

We will be participating in the NYC Open Data project gallery. The main objective of our project will be developing a website that shows an interactive map of NYC that allows users to see where 311 service requests occur. This would allow a user to answer questions like: “which borough had the most rat infestation 311 complaints in 2020 - 2025?” The dataset we will be using (found here) contains 23 million rows where each row represents an individual 311 service request with corresponding information. The fields which will be most important to the development of our project are:

  • create_date - in order to track complaints over time

  • complaint_type and descriptor - information about the nature of the 311 complaint

  • location type - filtering by residential building or sidewalk, etc.

  • incident_zip, incident_address, city, borough, location - geographic data which can be used to build the map

Initial Analysis

For the initial analysis below I will be using the nycOpenData library, which uses their api to import the data. Without an API key though, it restricts the size of import to 10,000 records, so the initial analysis will be done using that.

Map of pest complaints

pest_data = sample_311 |>
  filter(
    complaint_type == "UNSANITARY CONDITION" &
    descriptor == "PESTS"
  )

pal = colorFactor(palette = "Set1",
                  domain = pest_data$park_borough)
leaflet(data = pest_data) %>%
  addTiles() %>%
  addCircleMarkers(
    lng = ~longitude,
    lat = ~latitude,
    fillColor = ~pal(park_borough),
    color = ~pal(park_borough), # Colors the outer ring to match (or set stroke = FALSE)
  )
